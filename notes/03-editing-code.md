# 03 · Editing Code with Claude Code

- Use **`@`** to reference files directly (e.g. `@app.py`).
- **Paste images** straight into the terminal. Claude Code is multimodal, so screenshots and diagrams work.
- For **complex prompts**, write them in a separate file first (an LLM can help you craft them), then paste into Claude Code.
  - Makes prompts **reusable** and easier to refine over time.
