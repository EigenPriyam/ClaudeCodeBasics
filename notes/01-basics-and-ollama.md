# 01 · Claude Code Basics, Bash Mode & Ollama

## Launching
- Type `claude` in your terminal to start Claude Code.

## Bash mode
- Press **Shift + !** to instantly switch into bash mode inside Claude Code (run shell commands directly).

## Ollama integration
Claude Code is not limited to Anthropic's models; it can run on **Ollama** too.

- Ollama supports both **cloud models** and **locally downloaded open-source models**.
- Gives flexibility to work **offline** or with **custom models**.
- Get started: `ollama launch claude`

| Mode | How it works |
|------|--------------|
| Ollama → cloud | Access models hosted in the cloud |
| Ollama → local | Uses *your PC's* configuration. Better hardware = better results |
